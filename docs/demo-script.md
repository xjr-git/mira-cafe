# 演示录屏分镜脚本（3 分 40 秒，OBS 1080p）

> 建议同时录手机竖屏（投屏到电脑或分屏），至少保证主画面清晰。
> 录制前：清空 .env（Mock 模式）演示最稳；最后一镜可断网。

| 时间 | 镜头 | 操作 | 画外音要点 |
|---|---|---|---|
| 0:00–0:20 | 开场 | 手机竖屏打开页面：雨夜咖啡馆背景、Mira 待机（眨眼/呼吸） | "不是一个聊天列表，而是一个场景：暴雨夜的咖啡馆，Mira 在等人。" |
| 0:20–1:00 | 文字互动 | 输入"你为什么还没走？"→ 思考态 → 说话 + 字幕 + shy 表情 + 搅咖啡动作 | "角色的表情、动作、场景全部由回复中的结构化指令驱动。" |
| 1:00–1:50 | 语音 + **打断** | 按住 🎤 提问 → 回复播放中 → **再按 🎤** | "打断：语音立即停止，未播的字幕动作全部失效，切倾听态。" |
| 1:50–2:20 | 迟到防护 | 在她回复时**疯狂连按**打断 3 次 | "所有迟到响应被 round_id 过滤，永远不会诈尸重播。" |
| 2:20–3:10 | 多模态 | 问"给我看看你的照片"→ 拍立得显影动画 → 照片可看；继续聊到雨停 → **背景切换** | "对话触发的生成式媒体；生成等待被剧情化为显影动画。" |
| 3:10–3:40 | 降级 + Mock | 断网发消息 → 错误提示；说明无 Key Mock 模式；带一眼 /metrics 页 | "LLM 超时自动回落剧本模式，生图失败降级旧照片，任何情况不冷场。" |

上传：B 站「仅限链接访问」或网盘，链接写进投递消息。
